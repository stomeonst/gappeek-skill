# GapPeek

GapPeek helps AI agents research market size, demand, competition, pricing, and related market opportunities.

## Install

Send this command to your AI agent, or run it in a terminal:

```bash
npx skills add stomeonst/gappeek-skill --yes
```

## Use

Ask your agent to use GapPeek, then describe the market, category, or product direction you want to research.

Examples:

```text
Use GapPeek to research the US market for compact pet cleaning products.
```

```text
Use GapPeek to compare demand, seller competition, and price ranges for travel organizers.
```
